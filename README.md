# my nix-darwin and home-manager config

## GNU tools on macOS

Native macOS utilities keep their usual command names. GNU tools are available
with a `g` prefix, including `gsed`, `ggrep`, `gfind`, `gxargs`, `gawk`, `gmake`,
`gtar`, `gdiff`, and prefixed coreutils such as `gdirname` and `gtimeout`.

Helpers that require GNU behavior use explicit Nix store paths. `git-foreach` is
generated by Home Manager to pin its Bash, `realpath`, `dirname`, and `sort`
without changing the `PATH` inherited by commands it launches. Changes to its
source script require a rebuild.

## set up a macOS machine from scratch

1. install developer tools

```sh
xcode-select --install
```

2. install nix following the instructions at https://nixos.org/download.html

3. clone this repository

```sh
cd ~
git clone https://github.com/madmaxieee/nix-config.git
```

4. run the darwin configuration

```sh
sudo nix --extra-experimental-features 'nix-command flakes' \
  run nix-darwin/nix-darwin-25.05#darwin-rebuild -- switch --flake ~/nix-config
```

## first use on linux

```sh
nix --extra-experimental-features 'nix-command flakes' \
  run home-manager/master -- \
  --extra-experimental-features 'nix-command flakes' \
  switch --flake ~/nix-config
```

## rebuild on linux

```sh
home-manager switch --flake ~/nix-config#<target>
```
