# my nix-darwin and home-manager config

## Codex configuration

Edit `dotfiles/codex/config.toml` for managed fff MCP settings and
`dotfiles/codex/AGENTS.md` for global instructions. Home Manager links these
files and the existing hooks, then merges only the fff MCP settings into
`~/.codex/config.toml` on each rebuild. It also sets the `fff` MCP command to
the absolute Nix store path of `packages/fff-mcp.nix`, shared with OpenCode.

The live config stays writable for Codex's app settings, plugins, MCP servers,
and project trust state. The first merge saves `config.toml.before-nix` beside
it. Managed keys are reapplied on rebuild; removing a key from the managed
file leaves its current live value in place. To reset it, remove it from both
files. Restart Codex after rebuilding to load MCP changes.

## Claude Code configuration

Edit `dotfiles/claude/settings.json` for managed settings such as hooks. Global
instructions and the jj guard are shared with Codex: `~/.claude/CLAUDE.md` links
`dotfiles/codex/AGENTS.md` and `~/.claude/hooks/jj_guard.py` links
`dotfiles/codex/hooks/jj_guard.py`. The `fff` MCP server is defined in
`home/modules/claude.nix`, using the same `packages/fff-mcp.nix`.

On each rebuild, Home Manager merges the managed settings into
`~/.claude/settings.json` and the MCP server into `~/.claude.json`, which also
holds Claude Code's login and app state. Both stay writable, and the first merge
saves a `.before-nix` copy beside each. Managed keys are reapplied on rebuild,
and a managed list such as `hooks.PreToolUse` replaces the live one, so add hooks
to the managed file. Restart Claude Code after rebuilding.

## Antigravity CLI configuration

Home Manager manages `~/.gemini/config/mcp_config.json` from
`home/modules/antigravity.nix`, using the shared `packages/fff-mcp.nix` package.
Each rebuild replaces the whole MCP config, including any temporary local edits.
Global instructions at `~/.gemini/config/AGENTS.md` link the shared
`dotfiles/codex/AGENTS.md`, including the fff file search guidance.
Restart agy to load MCP changes.

## GNU tools on macOS

Native macOS utilities keep their usual command names. GNU tools are available
with a `g` prefix, including `gsed`, `ggrep`, `gfind`, `gxargs`, `gawk`, `gmake`,
`gtar`, `gdiff`, and prefixed coreutils such as `gdirname` and `gtimeout`.

Helpers that require GNU behavior use explicit Nix store paths. `git-foreach` is
generated by Home Manager to pin its Bash, `realpath`, `dirname`, and `sort`
without changing the `PATH` inherited by commands it launches. Changes to its
source script require a rebuild.

## set up a macOS machine from scratch

1. install developer tools

```sh
xcode-select --install
```

2. install nix following the instructions at https://nixos.org/download.html

3. clone this repository

```sh
cd ~
git clone https://github.com/madmaxieee/nix-config.git
```

4. run the darwin configuration

```sh
sudo nix --extra-experimental-features 'nix-command flakes' \
  run nix-darwin/nix-darwin-25.05#darwin-rebuild -- switch --flake ~/nix-config
```

## first use on linux

```sh
nix --extra-experimental-features 'nix-command flakes' \
  run home-manager/master -- \
  --extra-experimental-features 'nix-command flakes' \
  switch --flake ~/nix-config
```

## rebuild on linux

```sh
home-manager switch --flake ~/nix-config#<target>
```
